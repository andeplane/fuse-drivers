# Items, projectiles and effects (raw)

All 1024x1024 RGBA PNG with real alpha, generated at quality `medium` per `assets/raw/STYLE.md`. Note: the `gpt-image` CLI cannot send `background=transparent` (it only offers auto/opaque) and its first pass returned RGB with a painted checkerboard, so these were regenerated with the same prompts through the OpenAI SDK with `background="transparent"` forced, then cleaned with alpha < 32 set to 0 to remove faint haze the model paints around glows. Sprites sit on a uniform grid but are not pixel-aligned to cell boundaries; slice by bounding box, not by fixed cell size.
